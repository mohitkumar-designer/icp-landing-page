# ICP Analytics Landing Page — DiGGrowth

High-converting, responsive landing page for DiGGrowth's ICP Analytics agent ("Find Out Who Actually Buys").

## Features

- **Modern SaaS Aesthetics**: Sleek dark mode design system with curated typography, gradients, and micro-interactions.
- **Interactive Form**: Lead capture form with real-time validation and success confirmation.
- **Evidence Data Visualization**: Segment breakdown charts and win-rate gauges.
- **Fast & Responsive**: Fully responsive across mobile, tablet, and desktop viewports with zero external runtime dependencies.
