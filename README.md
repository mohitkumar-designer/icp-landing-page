## 🚀 Features

- **Modern SaaS Aesthetics**: Sleek dark mode design system with curated typography, glow gradients, and micro-interactions.
- **Lead Capture Form**: Interactive lead capture with real-time validation and animated confirmation state.
- **Evidence Data Visualization**: Segment breakdown charts and win-rate gauges.
- **Lightweight & High-Performance**: 100% self-contained HTML/CSS/JS without heavy external runtime libraries.

## 🛠 Local Development

Open `index.html` or `icp-landing.html` in any browser, or run a local server:

```bash
# Using python
python -m http.server 3000

# Using Node.js npx
npx serve .
```
